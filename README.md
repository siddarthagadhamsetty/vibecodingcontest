# Lahari — Economics, code, and match day

Personal portfolio for an Economics + Computer Science student at BITS Pilani, Hyderabad Campus, who plays badminton and football.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5173
```

Then visit http://localhost:5173

## What’s interactive

- Drag the line on the opening photo, or use the arrow keys on the handle.
- Shuttle / Pitch in the header restyles the page and changes the rally physics.
- Serve on the court and stay under the shuttlecock, or with the ball.
- Push the supply and demand sliders, or the three presets.
- Tap a name in the formation. Drag the photo strip.
